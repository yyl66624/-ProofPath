## 一 演示要传达的三件事（对齐 0 号文件 §3.4）

1. **用户少做了什么**：条件不用自己拆、材料不用自己拼、引用不用自己找。
2. **结论如何追溯到原文**：任意一条判定都能点回页码与逐字片段。
3. **系统遇到错误时如何处理**：编造引用被拦、过短引用被拦、敏感操作被拦、结论强制降级。

演示**不宣称**准确率、节省时间、获奖概率、"实时调用"这类未证实结论。演示模式是**离线预设 + `demo` 命令**，属于 0 号文件 §13.1 定义的"离线预设"，全程明示。

## 二 3 分钟演示脚本（B-7）

按 0 号文件 §13.1 分段：**20s + 50s + 50s + 40s + 20s = 3 min**。

### 2.1 段一 · 用户与问题（0:00 – 0:20）

**画面**：切到终端全屏；打开 `examples/policy.txt` 侧栏可见。

**旁白（照读）**：

> "假设我是一名硕士毕业生，28 岁，在本市工作 8 个月、社保交了 8 个月，
> 名下没有房，已经网签了租房合同。我想申请租房补贴，第一件事是搞清楚：
> **我够不够条件？要交哪些材料？截止时间怎么算？**
>
> 靠自己读政策 PDF 逐条拆，很容易漏读；把政策粘到通用大模型问答，
> 它会告诉你结论，但引用真假你没法核。
>
> ProofPath 做的事，是把政策变成有原文出处的结论，
> 而且——**它不信任模型自己说的话**。"

### 2.2 段二 · 上传文件并补充资料（0:20 – 1:10）

**动作**：在终端敲下：

```
proofpath parse examples/policy.txt
```

**旁白**：

> "系统按页解析文档，页码保留下来——这一点很关键，
> 后面每一条引用都会告诉我'在第几页'。"

**动作**：接着敲：

```
proofpath search examples/policy.txt -q "硕士 补贴标准 每月"
```

**旁白**：

> "先做一次检索，看看跟'硕士 补贴标准'相关的段落在哪。
> 命中第 2 页评分最高——这里放着补贴档次；第 1 页次之——放着适用条件。
> 全部是 BM25 词面检索，**没有向量数据库、没有外部服务**。"

### 2.3 段三 · 条件判定与原文定位（1:10 – 2:00）

**动作**：敲下：

```
proofpath demo
```

**旁白**：

> "这是完整的离线链路。DEMO 里用一份**故意留了两个缺陷**的预设回答，
> 演示的重点不是模型答对了，而是——**信任边界在系统里，不在模型里**。
> 我们把这条边界叫 `verify_report`——不管上游模型是 Claude 还是 DeepSeek，
> 每一条引用都要回到这里逐字对原文，没对上就整条降级。"

**画面停在输出，逐条讲解**（≤ 6 条，按顺序）：

- 学历 `[满足]` → "引用第 1 页……**已核验**"
- 年龄 `[满足]` → "引用第 1 页 **已核验**"
- 社保 `[满足]` → "引用第 1 页 **已核验**"
- **补贴标准** `[原文未明确]` →
  > "看这里，模型说了'硕士 1500 元，且首次申请可追补 3 个月'，
  > **前半句真、后半句是编造的**。
  > 系统对第二条引用做了逐字比对，**覆盖率只有 11%**——不在原文里。
  > 因为一条结论里任何一个引用无法定位就整条降级，
  > 用户不会看到'可追补 3 个月'这个不存在的承诺。"
- **劳动合同** `[原文未明确]` →
  > "这里引用只有'合同'两个字。**引用过短，不足为证**——
  > 两个字可以匹配任何政策页。系统把它当作证据不足处理。"
- 申请时限 `[待补充]` →
  > "备案的具体日期用户没说，系统直接问'你什么时候备案的'，
  > 不擅自替用户猜。"

### 2.4 段四 · 材料清单与敏感操作闸门（2:00 – 2:40）

**画面**：滚到 `## 材料清单` 那段。

**旁白**：

> "系统同时列出 7 项材料，每项对应原文条款可回溯。
> 这一步用户少做的是——不用自己把'第七条'和'第五条'拼在一起。"

**动作**：新开一段命令：

```
proofpath plan https://example.gov.cn/apply
```

**旁白**：

> "假设我们做到了真实提交这一步。系统按风险把每一步分级：
> **navigate / fill 是可自动的，upload / submit 是敏感操作**。
> 只要遇到敏感操作，**在这里停止、退出码 3、绝不留半成品**。
> 表单里含'支付'字样的字段会自动升级为敏感，白名单外的动作按敏感处理——
> 宁可多问一次，也不误提交一份政府申请。"

### 2.5 段五 · 实测结果、团队贡献、边界（2:40 – 3:00）

**旁白**：

> "本项目的可运行基线：132 项测试全部通过，覆盖率 90%，
> 记录在 `docs/baseline.md`。
>
> 已知边界三条：
> - 首版是**初步判断，不是最终资格认定**；报告末尾都会提醒。
> - **检索为词面匹配**，同义改写可能检索不到，此时系统会拒答而非编造。
> - **真实模型调用与浏览器执行器**尚未接线，本次演示是离线预设。
>
> 我们做的差异化点只有一个——**模型说的话不算数，原文对得上才算数**。
> 谢谢。"

## 三 备份录屏说明与故障回退（B-8）

### 3.2 录制脚本（照做）

1. 干净终端全屏，字体 ≥ 16pt，配色高对比（浅底深字或深底浅字二选一，别切换）。
2. 打开屏幕录制（Windows: `Win+G` → 屏幕录制，或 OBS）。
3. 在 `E:\-ProofPath-main\-ProofPath-main` 目录下按 §2 顺序执行五个命令，**每条命令之间停 3 秒**让观众看清输出。
4. 全程不切窗口、不接麦克风讲话（旁白后期字幕；或另录音轨）。
5. 保存为 `docs/assets/demo.mp4`，同目录留 `docs/assets/README.md` 记录：
   - 录制日期
   - 使用的提交哈希（`git rev-parse HEAD`）
   - Python 版本
   - 是否使用真实模型调用（本轮 = 否，标"离线预设"）

### 3.3 故障回退步骤（现场遇到）

按发生概率排序：

| 现象 | 现场处理 | 旁白话术 |
|---|---|---|
| 终端字体太小 / 输出太长 | 立刻 `Clear-Host` + 重启命令；或在命令后加 `\| more` 分页 | "把输出分页一下" |
| `proofpath demo` 报 `ModuleNotFoundError` | 切到备份录屏；说明"当前环境不完整，切到已交付版本录像" | "环境异常，我切到备份录屏，这段来自 commit `<hash>` 的实测输出" |
| 网络掉线 | 全程离线可跑，无影响 | 不必提 |
| 投影分辨率异常 | 切到本机屏幕做分身 / 镜像 | 短句"我调一下投影" |
| `plan` 命令输出与脚本不一致 | 说明"本机 CLI 输出可能因版本略有差异，实测记录在 docs/baseline.md" | 引用文档，避免临场解释 |
| 观众打断问技术细节 | 记下问题；答"3 分钟后 QA 时段回答" | 保护时长 |

**红线**：任何时候都不能把备份录屏说成实时执行。切到录屏时**必须口头明示**（0 号文件 §13.1）。

## 六 观众常见提问参考回答

以下答案不进入正式脚本；仅当被问到时用，控制在两句以内。

| 问 | 答（照读） |
|---|---|
| "准确率多少？" | "没有对照评测数据，不宣称具体准确率；我们展示的是'引用不真时系统会降级'的机制。" |
| "跟通用大模型问答比呢？" | "通用问答的引用无法核验；我们把每条引用逐字比对原文，编造的会被降级。具体对比走查计划记在 docs/research.md §3.3。" |
| "为什么不接真实浏览器？" | "首版不接。风险分级与确认闸门在 actions.py 里已经就绪；浏览器执行器接线不改变闸门逻辑。" |
| "支持扫描件吗？" | "首版不支持。装 docling 分支可用，但本次演示不启用。" |
| "有没有 Web 界面？" | "首版是 CLI。HTTP 接口与前端在后续工作包 P05 / P07 中，本次演示不涉及。" |
| "审计日志能防抵赖吗？" | "本地哈希链能检测**修改**，但不能证明日志**未被整体重写或尾部截断**。这是 0 号文件明确说明的边界。" |
| "为什么演示用离线预设？" | "真实模型链路已在脚本级验证过（见 docs/model-verification.md），但 20 例质量评估留给 P09；用离线预设演示是为了 3 分钟内可复现，同时避免网络失败。" |
| "如果模型出错会怎样？" | "被 verify_report 拦下并降级——`verify_report` 是本项目的**唯一信任边界**（见 docs/product.md §二·五）。demo 命令展示的两处缺陷就是走这条路径。" |
| "换成 DeepSeek 会不会不一样？" | "接线换成 openai SDK + DeepSeek 端点（见 docs/decisions.md D-012），但信任边界不动——`verify_report` 仍然逐字核验每一条引用。换模型只是换上游，不是换判定。" |
